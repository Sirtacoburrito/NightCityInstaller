Arasaka Estate Home（荒坂庄园变家）v1.1.0
================================================================
游戏版本：Cyberpunk 2077 2.5（含 Phantom Liberty）
说明：从 2.3 版移植；2026-10-29 在 2.5 实机验证通过。
安装方式：用 Vortex 安装本 zip，或把 zip 内容解压到游戏根目录
          （解压后应得到 bin\... 与 archive\... 两个目录）。

----------------------------------------------------------------
前置需求（必需，均需 2.5 兼容版）
----------------------------------------------------------------
- Cyber Engine Tweaks 1.38.1+
- ArchiveXL 1.28.0+
- Native Interactions Framework 1.1.4+
（不需要 RedHotTools）

----------------------------------------------------------------
功能
----------------------------------------------------------------
- 消除庄园的红色敌对标志（安全区改为 DISABLED，不影响战斗）
